# Notes Web App 📝

A full-stack Notes Web Application built using the MERN stack. Users can register, log in, create folders, and manage their notes.

## 🚀 Tech Stack

### Frontend

* React
* Bootstrap 5
* Bootstrap Icons
* Axios
* React Router DOM

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* bcryptjs
* dotenv
* cors

---

## ✨ Features

### Authentication

* User Registration
* User Login
* JWT Authentication
* Protected Routes
* Logout

### Folder Management

* Create Folder
* Display Folders
* Select Folder

### Notes Management

* Create Notes
* Edit Notes
* Delete Notes
* Folder-wise Notes Display

### UI

* Responsive Dashboard
* Sidebar Navigation
* Header Section
* Profile Avatar
* Bootstrap-based Design

## ⚙️ Installation

### 1. Clone the repository

 

cd project
 

 

## 🖥️ Frontend Setup

Open a terminal:

 
cd frontend

cd my-app

npm install

npm run dev
 

Frontend runs on:

 
http://localhost:5173
 

---

## ⚙️ Backend Setup

Open another terminal:
 
cd backend

npm install

npm start
 
Backend runs on:

 
http://localhost:5001
 

 

## 🔐 Environment Variables

Create a .env file inside the backend folder.

 
PORT=5001

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```
